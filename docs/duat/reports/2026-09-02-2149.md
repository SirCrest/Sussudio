### #1 — P0 security boundary: the automation pipe does not establish exclusive server identity

**Severity / confidence / class:** user-scale **High**, confidence **High**, confirmed root. Security focus raises Gate 6's P1 to DUAT P0; this is not a Fatal/RCE/elevation claim.  
**Files:** `Sussudio/Services/Automation/NamedPipeAutomationServer.cs:496-501,566-575,604-632`; `Sussudio.Automation.Contracts/AutomationPipeProtocol.cs:446-488`; `Sussudio/Services/Automation/AutomationCommandDispatcher.cs:353-377`.

## Gaps Identified (Gate 6)

1. **Automation endpoint ownership and identity:** actual DACL/logon/remote/mixed-integrity matrices, hostile first/competing instance, pre-secret server authentication, bounded response/framing, and correlation/idempotency need process-separated Windows tests.
2. **Recording truth and native ownership:** inject video drain, trailer, close, disk-full, delayed-write, COM refcount, failed init, worker-join, and close-during-recording faults; assert no uncertain artifact becomes “saved.”
3. **WASAPI negotiated layout and teardown:** exercise non-stereo/non-float/rate/block-align formats, device removal, callback races, and workers that outlive stop deadlines.
4. **Format-aware resource budgets:** measure resident/peak bytes, oldest-frame age, queue depth, coordinator backlog, A/V drift, and emergency-stop latency under supported 4K120 overlap.
5. **Flashback provenance and semantics:** test mixed content, two same-account sessions/processes, active leases, partial recursive deletion, live-edge export, first keyframe, expected duration/streams, and preserved recovery history.
6. **Process and text boundaries:** cap/drain/cancel `ffprobe`, PresentMon, labs, client responses, logs, and stderr/stdout; validate executable provenance and owned scratch outputs.
7. **Platform lifecycle:** qualify suspend/resume, hotplug, GPU reset, blocked source reads, clock skew, case-sensitive/reparse paths, disk removal, and long-idle behavior on target hardware.
8. **Release validation/provenance:** make a nonzero xUnit run, required tools/clients, native hashes/signatures, clean revision, package smoke test, SBOM, and publisher authentication mandatory for the produced archive.
9. **Filesystem object identity:** test aliases, symlinks/junctions, cross-process reservation, case variants, handle identity, and no-replace publication around every cleanup/output owner.
10. **Documentation/composition source of truth:** align the architecture map, command registry, protocol examples, XAML bindings, package contract, and final ViewModel construction policy.

## Methodology

- **Gate 1 — Contract extraction:** inventoried 605 contract units across 197 files and all critical owners; contracts were evidence, not defects.
- **Gate 2 — Journey tracing:** traced 21 user/destructive journeys and retained 733 provisional hazards through UI, app, native, file, and automation principals.
- **Gate 3 — Failure modes:** covered 33/33 mandatory scenarios, including eight security-focus scenarios, producing 253 provisional scenario records.
- **Gate 4 — Contract violations:** merged 301 source violations into 264 evidence-equivalent groups while preserving source IDs/severity hints.
- **Gate 5 — Standard review:** retained 16 genuinely new findings; shard 3 correctly returned zero new findings.
- **Gate 6 — Self-critique:** adjudicated all 1,313 stable rows: 386 confirmed, 326 downgraded, 363 duplicate, 136 false positive, and 102 needs-investigation; consolidated 182 gap bullets into 22 roots. Forty-six shard citations were degraded (31 shorthand/historical, 15 out of range) and were not used as sole confirmation.
- **Gate 7 — Synthesis:** applied every Gate 6 disposition, merged repeated scenario/caller symptoms into 35 ranked roots, retained all 102 unresolved IDs, calibrated 0 Fatal/8 High, and limited diff sketches to the eight final P0/P1 entries. No product code was changed.
- **Independent assessments/cross-checks:** reconciled architecture, security, documentation, validation, resource-risk, solution-challenge, high-severity calibration, settings truthfulness, and all 20 focused cross-check files. Closed candidates were not resurrected: successful recording-name overwrite, arbitrary path sandboxing, Native XU cross-device injection, product reachability of the HDR lab copy bound, and the dormant post-mux deletion branch remain excluded.
- **Supply chain:** the live `dotnet list Sussudio.slnx package --vulnerable --include-transitive --no-restore` result reported no vulnerable direct/transitive NuGet packages from current sources. Version drift was not treated as a defect.
- **Validation limits:** this is principally static evidence. Fresh app build and 944-test xUnit run passed; full solution build was blocked by live MCP output locks, and no hardware, cross-session, native fault-injection, or hostile Windows pipe matrix was run.
